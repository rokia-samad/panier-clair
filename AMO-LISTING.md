# Fiche Firefox Add-ons

## Nom recommandé

Panier Etiq — Nutri-Score, NOVA et additifs

## Résumé court

Nutri-Score, NOVA et additifs Open Food Facts sur E.Leclerc Drive. Affichez le code-barres pour le scanner dans Yuka.

## Description complète

### Les repères produit, directement pendant vos courses

Sur E.Leclerc Drive, Panier Etiq affiche dans les fiches et les listes de produits, lorsque le code-barres est disponible, les informations issues d’Open Food Facts :

- le Nutri-Score ;
- le groupe NOVA ;
- le nombre d’additifs renseignés.

Cliquez sur Nutri-Score ou NOVA pour ouvrir une page d’explication. Le bouton des additifs affiche leur détail ; chaque additif renvoie vers sa fiche Open Food Facts.

### Retrouvez aussi les informations Yuka

Vous pouvez afficher le code-barres du produit, puis le replier en cliquant de nouveau sur le bouton. Scannez ce code manuellement dans l’application Yuka pour consulter les informations proposées par Yuka, notamment sa note. **Panier Etiq ne calcule et n’affiche aucune note Yuka** : les repères présentés dans Drive proviennent d’Open Food Facts.

### Des données qui peuvent manquer

La disponibilité et l’exactitude des informations dépendent des données associées au produit dans Open Food Facts. Un produit absent ou incomplet peut ne pas afficher tous les repères.

### Vie privée

Pour rechercher les informations d’un produit, Panier Etiq transmet son code-barres à Open Food Facts. L’extension ne collecte ni identifiant de compte Leclerc, ni historique, ni donnée personnelle. Les résultats sont conservés 24 heures dans le stockage local de Firefox afin de limiter les requêtes.

Panier Etiq est un projet indépendant, sans affiliation à E.Leclerc, Open Food Facts ou Yuka.
