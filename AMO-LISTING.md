# Fiche Firefox Add-ons

## Nom recommandé

Panier Etiq — Nutri-Score, NOVA et additifs

## Résumé court

Affichez le Nutri-Score, le groupe NOVA et les additifs directement sur E.Leclerc Drive, grâce aux données Open Food Facts.

## Description complète

### Les repères produit, directement pendant vos courses

Sur E.Leclerc Drive, Panier Etiq affiche dans les fiches et les listes de produits, lorsque le code-barres est disponible, les informations Open Food Facts suivantes :

- le Nutri-Score ;
- le groupe NOVA ;
- le nombre d’additifs renseignés, avec leur détail après un clic.

Vous pouvez aussi afficher le code-barres du produit pour le scanner manuellement dans Yuka et consulter sa note dans l’application. **Panier Etiq ne calcule et n’affiche aucune note Yuka** : les repères présentés dans Drive proviennent d’Open Food Facts.

### Des données qui peuvent manquer

La disponibilité et l’exactitude des informations dépendent des données associées au produit dans Open Food Facts. Un produit absent ou incomplet peut ne pas afficher tous les repères.

### Vie privée

Pour rechercher les informations d’un produit, Panier Etiq transmet son code-barres à Open Food Facts. L’extension ne collecte ni identifiant de compte Leclerc, ni historique, ni donnée personnelle. Les résultats sont conservés 24 heures dans le stockage local de Firefox afin de limiter les requêtes.

Panier Etiq est un projet indépendant, sans affiliation à E.Leclerc, Open Food Facts ou Yuka.
