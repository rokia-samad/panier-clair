# Fiche Firefox Add-ons

## Résumé

Repères Open Food Facts sur E.Leclerc Drive : Nutri-Score, NOVA, additifs et code-barres à scanner dans Yuka.

## Description

Panier Clair ajoute des repères de qualité aux fiches produit et aux listes de courses E.Leclerc Drive.

Lorsqu’un code-barres est disponible, l’extension affiche les informations correspondantes issues d’Open Food Facts :

- le Nutri-Score ;
- le groupe NOVA ;
- le nombre d’additifs renseignés ;
- un code-barres affichable pour être scanné dans l’application Yuka.

Panier Clair ne calcule ni n’affiche de note Yuka. La note officielle reste à consulter directement dans l’application Yuka après le scan du code-barres.

## Vie privée

Pour rechercher un produit, Panier Clair transmet son code-barres à Open Food Facts. L’extension ne collecte ni identifiant de compte Leclerc, ni historique, ni donnée personnelle. Les résultats sont conservés 24 heures dans le stockage local de Firefox afin de limiter les requêtes.

Politique de confidentialité : https://github.com/rokia-samad/panier-clair/blob/main/PRIVACY.md
