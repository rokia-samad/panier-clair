# Notes de version

## 0.3.3

- Le bouton du code-barres permet maintenant de l’afficher puis de le replier.
- Les repères Nutri-Score et NOVA ouvrent leurs pages d’explication.
- Chaque nom d’additif détaillé ouvre sa fiche Open Food Facts.
- Le code-barres peut être scanné manuellement dans Yuka. Panier Etiq ne calcule ni n’affiche de note Yuka.

Les informations produit affichées dans l’extension proviennent d’Open Food Facts.
